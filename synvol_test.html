Synapse volume decode — Stage 2 feasibility test

Decodes the RAW synapse segmentation volume directly (not the mesh — see synmesh_test.html for that, confirmed working). This is the piece that finds synapse segment IDs near a voxel/cell, since this dataset has no CAVE table to query instead. Voxel coordinates here are in this viewer's native 8×8×30 nm frame — the same numbers you'd read straight out of Neuroglancer's position box.

1. Single-voxel lookup

The critical test: pick a synapse you already know the ID of (e.g. segment 545931, confirmed via synmesh_test.html) and find its voxel coordinates by clicking it in Neuroglancer with the wei_synapses layer visible. Enter those coordinates below — if this decoder is right, the returned ID should match.

2. Box search

Scans a voxel box and lists every distinct segment ID found. Keep the box small (a few dozen voxels per side, stride 1-2) — this samples every voxel in the box client-side, one HTTP round trip per not-yet-fetched chunk.
